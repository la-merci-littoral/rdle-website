# Ronde de l'Espoir

Code source du site Internet de la Ronde de l'Espoir.

La branche `v1` contient la version de 2023, donc seulement le site vitrine (le site de donation se trouve dans un autre repository, maintenant laissé de côté), et la branche `v2` la version en cours de développement, en prévision de la Ronde de l'Espoir 2026.
